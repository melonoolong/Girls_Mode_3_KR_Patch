# 걸즈 모드 3 반짝반짝☆코디 한국어 패치

<p align="center"><img src="images/logo.png" width="361" alt="걸즈 모드 3 반짝반짝☆코디 한글 로고"></p>

닌텐도 3DS 일본판 『GIRLS MODE 3 キラキラ☆コーデ』(걸즈 모드 3 반짝반짝☆코디)용 비공식 한국어 번역 패치입니다.
게임 파일은 배포하지 않으며, 본인이 가진 원본에 적용하는 차분 패치와 자동 패처만 제공합니다.

> ⚠️ **v0.5.0-beta는 초반부를 플레이하며 확인한 시험판입니다.** 오역, 어색한 문구, 칸을 넘는 글자, 멈춤이 남아 있을 수 있습니다.

> ⚠️ **설치하면 기존 세이브가 지워집니다.** 설치 전에 Checkpoint 등으로 세이브를 백업하고, 설치 후 복원하세요.

## 준비물

둘 중 하나가 있으면 됩니다. 패치하지 않은 원본이어야 합니다.

- **Rev 3 카트리지 덤프** `.3ds` 하나 (파일 이름 끝이 `(Rev 3)`)
- **e숍판** 본편 CIA + 업데이트 3.3.0 CIA

DLC CIA는 있으면 함께 패치합니다. 암호화된 파일이라면 GodMode9으로 뽑은 `boot9.bin`(e숍판은 `seeddb.bin`도)을 같이 넣으세요.

## 패치하기

1. ZIP을 풀고, 게임 파일을 `한글패치_실행.bat`과 같은 폴더에 넣습니다.
2. `한글패치_실행.bat`을 실행합니다. `.3ds`를 넣었다면 CIA와 `.3ds` 중 무엇을 만들지 묻습니다(Enter = CIA).
3. `한글패치_결과` 폴더에 **`GM3_본편+업데이트_한글패치.cia`**(또는 `.3ds`)가 생깁니다. 이것 하나만 설치하면 됩니다.

맥·리눅스는 같은 폴더에서 `python3 patcher/gm3kr_patch.py`를 실행합니다(파이썬 3.9 이상, 암호화된 파일이면 `pip3 install pyctr`).

## 설치

- **실기**: FBI로 설치합니다. **일본어 업데이트가 깔려 있으면 먼저 지우세요**(남아 있으면 일본어로 나옵니다).
- **Citra / Azahar**: CIA를 설치하거나 `.3ds`를 바로 엽니다. 일본어 업데이트는 마찬가지로 지웁니다.
- **플래시카트**: `.3ds`를 씁니다.

### 지원 원본

| 항목 | 타이틀 ID | 버전 |
|---|---|---|
| 본편 | `000400000012D800` | v0.0.0 (e숍판) / Rev 3 (카트리지) |
| 업데이트 | `0004000E0012D800` | v3.3.0 (게임 안에서는 Ver. 1.2.0으로 표시) |
| DLC | `0004008C0012D800` | v0.13.0 |

- 초판·Rev 1·Rev 2 카트리지는 덤프가 없어 확인하지 못했습니다. 다른 판이면 패처가 알려 주고 멈춥니다.
- 패처는 파일 전체가 아니라 안에 든 게임 파일 하나하나를 확인합니다. 그래서 같은 판이면 덤프 방법(암호화, 트리밍, CIA 도구)이 달라도 됩니다.

### 결과 파일

- `GM3_본편+업데이트_한글패치.cia` / `.3ds`: 업데이트 내용까지 합친 한글판입니다. 이것만 설치하면 됩니다.
- `GM3_업데이트_3.3.0_한글패치.cia`: 업데이트 CIA를 넣었을 때 함께 만들어집니다. 설치하지 않아도 되며, 깔려 있는 일본어 업데이트를 덮어쓸 때 쓸 수 있습니다.
- `GM3_DLC_한글패치.cia`: DLC를 넣었을 때 만들어집니다.
- 이미 만들어진 결과는 다시 만들지 않습니다. 나중에 DLC CIA만 넣고 다시 실행하면 DLC만 만듭니다.
- 결과 파일 크기만큼(약 1GB, 암호화된 파일이면 약 2GB) 빈 공간이 필요합니다.

### 문제 해결

- **일본어와 빈칸이 섞여 나옴**: 일본어 업데이트(3.3.0)가 깔려 있습니다. 지우거나 한글 업데이트 CIA로 덮어 설치하세요. 업데이트를 지워도 세이브는 남습니다.
- **여러 CIA를 한 번에 설치하기**: CIA를 SD카드의 한 폴더에 모아 두고, FBI에서 그 폴더의 `<current directory>` → **Install all CIAs**.
- **홈 메뉴 제목·설명서가 일본어**: 한국어 글꼴이 없는 본체(일본판 등)에서는 일본어로 나옵니다(정상).
- **이름 입력**: 본체의 시스템 키보드를 씁니다. 한국어 키보드가 있는 본체(한국판, Citra/Azahar)에서 한글 이름을 입력할 수 있습니다. 완성형 2,350자만 표시됩니다.

## 현재 상태 (v0.5.0-beta)

- 대사·선택지·메뉴·아이템 이름·미키피디아 등 게임 안 문장 전체와, 글자가 그림으로 된 버튼·제목 약 370장을 한글로 옮겼습니다.
- 손님 이름에 맞는 조사(은/는, 이/가 …)와 말투에 맞는 1인칭·인사가 자동으로 붙습니다.
- 홈 메뉴 제목·배너, 전자 설명서, DLC 아이템 이름도 한글입니다. 돈 단위는 원작 그대로 엔입니다.
- 확인 환경: 실기와 Citra.

문제를 발견하면 Issues에 장면, 스크린샷, 사용한 환경(실기/에뮬레이터)을 알려 주세요.

## 글꼴·라이선스

글꼴 파일은 담지 않고, 아래 글꼴로 미리 그린 글자 그림만 게임 자료에 넣었습니다.

- 게임 글꼴·그림 글자: Noto Sans KR ([SIL OFL 1.1](licenses/OFL-NotoSansKR.txt))
- 이름 색인 탭 글자: 나눔스퀘어라운드 EB ([SIL OFL 1.1](licenses/OFL-NanumSquareRound.txt))

자동 패처에는 공식 임베디드 파이썬(PSF)과 pyctr(MIT), pycryptodomex(BSD/퍼블릭 도메인)가 들어 있습니다. 라이선스는 ZIP의 `python/` 폴더에 있습니다.

## 면책

- 이 프로젝트는 팬 번역이며 닌텐도, 신소피아와 관련이 없습니다. 관련 상표·저작물의 권리는 각 권리자에게 있습니다.
- 게임 파일과 본체 키 파일은 제공하지 않습니다. 본인이 소유한 원본으로만 사용해 주세요.
